Pasta 'Scripts/" contém os scripts usados para as análises
Pasta 'Plots/' contém os plots gerados com os resultados das análises
* Script 'análises_cap1_doc.R'
  * 'data,fito' - matriz de dados contendo espécies nas linhas e as fitofisionomias onde foram encontradas, com valores em abundància amostrada
  * 'data_par' - matriz de dados contendo parcelas nas linhas e espécies nas colunas, com valores em abundância amostrada
  * 'bird_matrices' - matriz de dissimilaridade de Bray-Curtis entre as 56 parcelas amostradas
  * 'groups' - fator classificando as parcelas de acordo com suas fitofisionomias
  * 'col_fito2' - paleta de cores para cada fitofisionomia
